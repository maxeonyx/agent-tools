# Version visibility

Anyone who needs to know what is live can find out, at the moment they need it.

## User stories

- **Max, after a release:** "is the fix live?" should take seconds, for the binary on this machine and for the site.
- **An agent reading a bug report:** which version is the reporter running, and at which commit?

## What it looks like here

- CLI tools: `<bin> --version`, and `--version --json` naming the release and commit.
- Sites: `/version.json` at the site root, written by the deploy, not by hand.
- The umbrella: `docs/version.json` names every pinned tool, and its site serves it.
- Libraries (help-test): the tag consumers pin is the version.

## How to look

- For each tool with a release: `<bin> --version --json` from a release binary, or `cargo run -q -- --version --json` in its checkout; `curl -s https://<site>/version.json`.
- Is the site's version file generated by the deploy or committed by hand? Read its `pages.yml`.
- Judgment: could the person who needs the answer get it without knowing where to look?
